## 🇬🇧 English

### Overview

DnA is a responsive front-end project for a fictional science and technology media company, designed to make scientific content more accessible to a broad audience.

The project takes the form of a single-page editorial website combining science communication with a modern visual identity. Its structure includes a hero section, thematic navigation across scientific disciplines, dedicated Education, Donation and Mission sections, and a social media footer.

The current version focuses on the design and implementation of the front-end experience using HTML and CSS, with particular attention to visual hierarchy, content organization and responsive behavior across different screen sizes.

The project is currently a **Work in Progress** and will be further developed and refined.

### Current Features

- Responsive single-page layout
- Semantic HTML structure
- Navigation and hero section
- Scientific topic grid
- Education, Donation and Mission sections
- Reusable buttons and visual components
- CSS custom properties for colors and typography
- CSS Grid and Flexbox layouts
- Responsive breakpoints for desktop, tablet and mobile
- Hover states and smooth scrolling
- Custom visual identity for a science-oriented editorial platform

### Technologies

`HTML5` · `CSS3` · `CSS Grid` · `Flexbox` · `Responsive Web Design`

### Panoramica

DnA è un progetto front-end responsive dedicato a una media company immaginaria di scienza e tecnologia, progettata per rendere i contenuti scientifici più accessibili a un pubblico ampio.

Il progetto consiste in un sito editoriale single-page che combina divulgazione scientifica e identità visiva moderna. La struttura comprende una hero section, una navigazione tematica tra diverse discipline scientifiche, sezioni dedicate a Education, Donation e Mission e un footer con collegamenti social.
